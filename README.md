## The word

**Yesterday**

## Why it should win

Every boss runs on the same clock, and it is set one day fast. The report
was due Friday; he needed it yesterday. The order came in this morning; he
needed it yesterday. Nobody has to explain the joke, because everybody has
lived it — in an office, on a warehouse floor, in a kitchen mid-rush. It is
not the first word anyone reaches for (those are "strict" and "bossy"), but
it is the one a colleague repeats at lunch, because it is funny precisely
because it is true: asked to describe the boss in a single word, the honest
answer is the deadline he lives by.

## Run

`python3 main.py` writes the word to `/output/entry.txt` (override with the
`ENTRY_OUTPUT` env var for local testing). No trailing newline.
